# Music

The gramophone plays the tracks listed in `src/data/playlist.ts`, on loop, fading in to a soft 30% volume.
The default track is `gymnopedie-1.mp3`: Erik Satie, Gymnopédie No. 1, performed by Robin Alciatore for
Musopen (public domain, from Wikimedia Commons). The playlist also lists `idea10.mp3` ("Idea 10" by Gibran
Alcocer), which you need to add yourself, with the rights to stream it.

If a track's file is missing, a small generative lo-fi loop is synthesised in the browser instead.
