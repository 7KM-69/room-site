# Optional GLTF models

Drop `desk.glb` here to replace the procedural desk. It's scaled so its height matches the desk top
(0.76 m) and centred on the desk's footprint. If there's no file, or it fails to load, the built-in desk
is used. Free CC0 desks: Poly Haven (polyhaven.com/models), Sketchfab (filter: downloadable + CC0/CC-BY).
