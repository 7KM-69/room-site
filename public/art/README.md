# Wall art

The wide frame over the desk shows `wide.png` from this folder (`WIDE_ART` in `src/scene/wallArt.ts`). The frame
is 5:3; other shapes are cropped to fill it around the centre. To use another file name, change `local` there.

The earlier small frames (Nietzsche, the 1933 Palestine map, Ibn Rushd) are still defined as `ART` in the same
file, loading from Wikimedia Commons or `nietzsche.jpg`, `palestine-map.jpg`, `ibn-rushd.jpg` here.
